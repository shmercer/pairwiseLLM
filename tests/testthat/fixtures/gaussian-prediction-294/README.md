# Gaussian prediction regression fixtures (#294)

`d020-scalars.csv` is copied unchanged from the public study artifact
`results/repro/d020-gaussian-prediction-fixtures.csv` at
`shmercer/pairwise-linking-study` commit
`a74f4869b4dcc78a3d8c949b92ef377c7320f0c8`.
The D020 contract was frozen at `12ca9b8e4b98faa6113904276527fc4dcbc0ea5f`.
Only scalar contrasts, controls and numerical references are included; no study
identities, outcomes, prompts, or raw provider artifacts are present.

The prospectively specified absolute reference tolerance is 1e-9. Tests also
construct independent standard-Normal GH256/GH512 references using the
Golub-Welsch Jacobi eigendecomposition. The global adaptive error-estimate
criterion remains max(1e-11, 1e-9 * abs(value)) for these production controls.

`baseline-03cc16c.rds` contains small synthetic E1/E2/E3 fits and predictions,
plus 20 already-successful scalar cases, generated by the original package
commit `03cc16c5953d9b1a74345c97324ebd6578248040`, version 1.6.0.
Generation used R 4.6.1 and `scripts/capture-issue-294-baseline.R`, before the
prediction implementation was edited. To reproduce, run that script with a
clean checkout of the old commit and the desired output RDS path. Timings within
fit diagnostics can differ; the saved fits must not be regenerated by ordinary
tests. These are synthetic package fixtures, not D018 study fits.
